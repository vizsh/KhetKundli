# Glossary

| Term | Meaning |
| --- | --- |
| **Adat, adatya** (अडत, अडत्या) | Commission; the commission agent who auctions the farmer's lot at the APMC and pays the farmer after deductions |
| **APMC** | Agricultural Produce Market Committee: the regulated market yard (Phaltan APMC; Pune market yard; Vashi APMC in Navi Mumbai) |
| **Bahar** (बहार) | Forced flowering in pomegranate by withholding water and pruning. **Ambia** bahar flowers in Jan–Feb, **Mrig** in Jun–Jul, **Hasta** in Sep–Oct |
| **Bhagwa** | The main pomegranate variety grown in the area (saffron-red arils) |
| **Crate** | The unit for pickings and transport; the engine uses about 20 kg a crate |
| **ET0** | Reference evapotranspiration (mm/day): how much water a reference crop would use today, from the weather. Multiplied by a crop coefficient **Kc** for the stage |
| **FPO** | Farmer Producer Organisation: a farmers' company that aggregates produce and negotiates with agents and buyers |
| **Gat number** (गट क्रमांक) | The land-record survey number that identifies a plot in the village |
| **H3** | A global grid of hexagons. KhetKundli uses resolution 7 (cells of about 5 km²) so that shared maps never show a single farm |
| **Hamali** (हमाली) | Loading and unloading charge, per crate |
| **Kundli** (कुंडली) | A birth chart. Here, the plot's season record that keeps updating |
| **KVK** | Krishi Vigyan Kendra: the district farm science centre that runs extension work |
| **Leaf-wet hours** | Hours in a day when the canopy is wet (rain, or relative humidity at or above 85%) at 18 to 35 °C: the weather in which bacterial blight moves |
| **Modal price** | The most common auction price on a day at a market, as published by Agmarknet |
| **Motor bhada** (मोटार भाडे) | Freight |
| **Patti** (पट्टी) | The sale slip the agent gives the farmer: lot, weight, rate, gross, deductions, net |
| **PHI** | Pre-harvest interval: the minimum days between a spray and picking, from the product label |
| **Pooled run** | One vehicle carrying several farmers' crates from a village collection point to the market |
| **Rate card** | The deductions the FPO agreed with an agent for pooled lots: commission %, hamali and weighment per crate, freight per crate |
| **Ripple** | What KhetKundli shows when an event changes the season: the list of consequences across modules |
| **Telya** (तेल्या) | Bacterial blight of pomegranate, *Xanthomonas axonopodis* pv. *punicae*; named for the oily spots on leaves and fruit |
| **Tolai** (तोलाई) | Weighment charge |
| **Override** | An event that changes the simulated season: a scan, a rain forecast, a picking date, an advisory, a sale slip |
